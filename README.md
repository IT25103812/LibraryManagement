# Library Management System 💻

A simple Java console-based application for managing library books.

## Features

- Add new books
- View all books
- Borrow books
- Return borrowed books
- Simple menu-driven interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class
